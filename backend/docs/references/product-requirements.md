## 页面 A：按公司分组的 Gmail 收件箱

目的：帮助销售快速识别应优先处理的客户。

| 区域 | 功能 |
|---|---|
| 顶部与渠道入口 | 全球洞察 / 社媒情报入口、同步状态、用户信息；当前 Gmail 可用，其余四个渠道禁用并提示预留 |
| 概览 | 公司组数、未建档客户数、今日新邮件数 |
| 公司行 | 公司名、头像首字、域名、联系人、邮件数、最近时间、CRM 建档状态、最新消息摘要 |
| 分析标签 | 行业、规模、业务信号、AI 跟进优先级分数及进度条 |
| 查询操作 | 按行业、规模、信号筛选；各项可重置；默认按优先级分数降序 |

产品列出的行业：半导体检测、精密量测、光学检测、工业检测。

规模展示：50–100、100–200、200–500、500+ 员工。边界值如何归属、低于 50 人和未知规模如何显示，需要与 Agent 枚举及接口对齐。

明确修订后的业务信号为四类：新线索且未建档、询盘、已报价未成交、复购。“全部”是筛选操作，不是业务信号；“在手商机”已在修订段落中删除。

## 页面 B：三栏客户工作区

| 区域 | 功能 |
|---|---|
| 左栏：邮件与回复 | 邮件时间线，全部 / 收件 / 发件筛选，中文翻译展开，回复草稿；区分空草稿、已填未发、已发送 |
| 中栏：客户信息 | 公司介绍与标签、画像、AI 分析、商机与订单、联系人；打开详情自动分析，未知信息置灰 |
| 右栏：AI 助手 | 结合邮件、客户、商机、订单及知识提供对话、处理步骤、文件和动作 |

按后文明确修订，客户画像采用三个文字维度：

- 行业情况。
- 公司经营分析：规模、决策、采购及历史合作等。
- 意向分析。

AI 客户分析采用四个维度：时间轴、商机、风险、建议如何引导。取消“成交可能百分比”，用文字解释依据和缺失信息。

右栏五类快捷任务：梳理历史与需求、起草回复、制定推进计划、生成对比材料、分析风险，并支持自由输入。产品还提出结合近期行业资讯解释客户动机，以及帮助未建档线索判断“缺什么、是否值得跟进、首封如何回复”。

## 用户操作与状态约束

1. Gmail 授权并同步，邮件按公司组织后进入列表。
2. 销售筛选客户、打开详情，阅读往来、画像与分析。
3. 助手生成建议或回复，用户确认后填入草稿。
4. 用户点击发送，展示实际发送结果、时间及内容。
5. 只有实际发送成功后，才将约定的抽取业务字段写回业务记录。

因此应区分“生成建议”“填入草稿”“请求发送”“发送成功”“业务写回完成”，不能将生成文本视为完成外部动作。具体发送与写回接口尚待设计。

## 文档内部冲突与跨文档差异

| 原文情况 | 本地摘要处理 |
|---|---|
| 前部筛选描述仍出现“在手商机”，后文明确删除 | 归纳四类有效信号，将旧描述视为待清理残留 |
| 早期界面说明和输出表仍有旧六项画像及概率字段，后文明确修改 | 按三维画像、四维分析和无概率百分比归纳；仍需团队同步清理原文和最终字段表 |
| 公司列表有 AI 分数，详情取消成交概率 | 二者含义不同：列表是跟进优先级，不能解释为成交概率 |
| 产品描述包括知识库、行业新闻、助手、翻译及发送 | Agent v1.11 将这些排除在其模块 MVP 外；本摘要保留产品需求，不将其自动分配给后端或 Agent |
